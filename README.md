# Houses

House Ledger

House-themed mockup of the Lanterncorps habit tracker: 0104 Gryffindor, 0211 Ravenclaw, 0814 Hufflepuff.

- `index.html` — daily ledger for all three houses, with House Cup standings (10 pts per task, +50 for a full day, +20 for the weekly review)
- `workout.html` — Legs / Upper / Full workout, opened with TRAIN

Uses its own Firebase data (`house_ledger_v1`, `house_workouts_v1`), so the real Battery Log is never touched.
